# D3 Match offer answer

D3 answers a [D2/00 MuchMake](D2.md#d200-muchmake) offer. The client sends
it to the [room service](../services.md#room-service) of the room it
entered, whichever nickname sent the offer. The proposal rules are in
[event-matches.md](../../flows/event-matches.md#sequence).

## D3/00 MuchMakeAns

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | room service | 0 | [D2/01 MuchMake start](D2.md#d201-muchmake-start) once every participant has answered | `struct MuchMakeAns` |

```c
struct MuchMakeAns {
    uint32_t Ans;         // 0 declines, 1 accepts
    uint32_t TblNo;       // echoed from the offer
    uint64_t TblId;       // echoed from the offer, 16 hex
};
```

```
C2S GTM0GD3000000@MuchMakeAns=/Ans=1/TblNo=1/TblId=0123456789ABCDEF
```

A server starts the table with `Start=1` only after every participant
answered `Ans=1`.

Server choice: a server retries a declined offer after 2
seconds.
