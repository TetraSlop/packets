# 98 Event match request

98 asks the [event match service](../services.md#event-match-service) of an
event room to admit the client to an event match. The service answers with
[99/00 EInitEnt](99.md#9900-einitent). The admission and the round that
follows are in [event-matches.md](../../flows/event-matches.md).

## 98/00 EInitReq

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | event match service | a sequence number chosen by the client; the reply echoes it | [99/00 EInitEnt](99.md#9900-einitent) | `struct EInitReq` |

```c
struct EInitReq {
    uint64_t NN;          // account identity, 16 hex; must match the authenticated account; the member key
    uint32_t HID;         // POL handle index, must fit 32 bits
    uint32_t Dm;          // profile directory number, must fit 8 bits
    uint32_t Vol;         // profile volume number, must fit 16 bits
    uint8_t  CN[16];      // character name, hex; must match the account
    uint64_t GID;         // 16 hex; not the member key, purpose unknown (unverified)
};
```

```
C2S GTM0G98000001@EInitReq=/NN=0123456789ABCDEF/HID=0/Dm=1/Vol=1/CN=416C696365/GID=0000000000000001
```

The client sends the request once it is present in the event room. A server
finds the member by `NN` and answers with
[99/00 EInitEnt](99.md#9900-einitent).
