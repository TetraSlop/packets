# 70 Prize Center request

70 opens a Prize Center session. The client sends it to the shop service
([services.md](../services.md#shop-service)), which also runs the Prize
Center. The sequence is in [prize-center.md](../../flows/prize-center.md).

## 70/00 CvReq

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | shop service | 0 | [71/00 CvEnter](71.md#7100-cventer) | `struct CvReq` |

```c
struct CvReq {
    uint64_t NN;          // player game identity, 16 hex; must match the authenticated account
    uint32_t HID;         // POL handle index
    uint32_t Dm;          // 0..255, purpose unknown (unverified)
    uint32_t Vol;         // 0..65535, purpose unknown (unverified)
    uint8_t  CN[16];      // character name, hex; must match the account
};
```

```
C2S GTM0G70000000@CvReq=/NN=0000000000000001/HID=0/Dm=0/Vol=0/CN=4C6F63616C506C61796572
```

The fields are those of the shop [ShReq](B0.md#b000-shreq). A server
replies with CvEnter and then [B2/13 Init](B2.md#b213-init) in its Prize
Center form, which carries the session number.
