# 84 Opt

The options editor saves all player options in one message. The target
service is not recorded (unverified); a server should accept it on any
service the client is attached to, see [services.md](../services.md). The
reply is [85/00 OptAns](85.md#8500-optans); when the editor is used is in
[startup.md](../../flows/startup.md#later-saves).

## 84/00 Opt

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | service it is attached to (unverified) | 0 | [85/00 OptAns](85.md#8500-optans) | `struct Opt` |

```c
struct Opt {
    uint64_t NN;      // game identity, 16 hex digits
    uint32_t HID;     // POL handle slot; always 0
    uint8_t  Dm;      // profile directory, the `D` of TeachDVAns
    uint16_t Vol;     // profile volume, the `V` of TeachDVAns
    uint8_t  CN[16];  // character name as hex byte pairs
    uint8_t  Ar;      // option, 0..1
    uint8_t  Cu;      // option, 0..255, kept as a raw byte
    uint8_t  Vi;      // option, 0..255, kept as a raw byte
    uint8_t  Se;      // sound effect volume, 0..3
    uint8_t  Bgm;     // music volume, 0..3
    uint8_t  Per;     // trade requests, 1 accept
    uint8_t  Ran;     // ranking name privacy, 0 display the name, 1 hide it
    uint8_t  CMD;     // option, 0..1
    uint8_t  CAD;     // option, 0..1
    uint8_t  CL;      // chat lines, 0..20
    uint8_t  CT;      // chat transparency, 30..70
    uint8_t  HNSS;    // option, 0..1
};
```

```
C2S GTM0G84000000@Opt=/NN=0000000000000001/HID=0/Dm=1/Vol=1/CN=416C696365/Ar=0/Cu=0/Vi=2/Se=2/Bgm=1/Per=0/Ran=0/CMD=0/CAD=0/CL=5/CT=60/HNSS=0
```

Each option is a decimal byte stored in the save file; the offsets and
bounds are in [save-file.md](../../file/save-file.md#rules).

`Ran` is the ranking name privacy flag. The result screen's Continue
message (43/11) carries the same flag as `PR`, so either message may change
the saved byte. The ranking display shows an anonymous label instead of the
name when the row's privacy byte is set.
