# 21 Trade invitation

The inviter's trade invitation, sent to the invitee through the server's
relay. It is the first message of [trade.md](../../flows/trade.md).

## 21/00 Tr

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| P2P | relayed | 0 | [22/00 TrAns](22.md#2200-trans) | `struct Tr` |

```c
struct Tr {
    uint64_t NN;          // inviter's game identity, 16 hex
    uint32_t HID;         // inviter's POL handle index
    uint32_t Dm;          // inviter's profile directory number
    uint32_t Vol;         // inviter's profile volume number
};
```

```
P2P GTM0G21000000@Tr=/NN=0000000000000001/HID=0/Dm=0/Vol=0
```

The body is one section. The example is built from the field list; no
capture of it is recorded (unverified). A server relays it only between a
pair allowed by the [peer relay guard](../envelope.md#relay-guard) and
does not answer it; it records the invitation so that a later
[A0/00 TrEnt](A0.md#a000-trid-and-trent) can be checked against it.
