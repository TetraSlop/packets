# 71 Prize Center entry

71 acknowledges a [70/00 CvReq](70.md#7000-cvreq). The shop service
([services.md](../services.md#shop-service)) sends it before the Prize
Center session opens. The sequence is in
[prize-center.md](../../flows/prize-center.md).

## 71/00 CvEnter

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | shop service | 0 | none | `struct CvEnter` |

```c
struct CvEnter {
    uint32_t EN;          // 1, entry accepted
};
```

```
S2C GTM0G71000000@CvEnter=/EN=1
```

The client then waits for [B2/13 Init](B2.md#b213-init) in its Prize
Center form, which carries the session number.
