# 1A GameOwner

The owner notice the [room service](../services.md#room-service) publishes
to a table after each roster change. Its place after an Apply or a
departure is in [tables.md](../../flows/tables.md#sequence)
and [match-admission.md](../../flows/match-admission.md#exit).

## 1A/00 GameOwner

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service to every table member | 0 | none | `struct GameOwner` |

```c
struct GameOwner {
    uint64_t NN;     // owner's nickname identity, sixteen hex digits
    uint8_t  CN[16]; // owner's character name, hex bytes
    uint64_t QN;     // identity of a member who just left; present only when the roster shrinks
};
```

```
S2C GTM0G1A000000@GameOwner=/NN=0000000000000001/CN=416C696365
```

A server sends it after the `TD` delta and [41/04 GameML](41.md#4104-gameml).
The client compares `NN` with its own identity to decide whether it is the
owner. The notice does not replace the owner field in the table metadata; a
server must publish both.
