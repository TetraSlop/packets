# D1 Event time

D1 carries an event room's schedule: one query with its answer, and
unsolicited notices the [room service](../services.md#room-service) pushes
to every member. When a server sends each notice and what the client
derives from them is in
[event-rooms.md](../../flows/event-rooms.md#rules).

## D1/01 EventTime start

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct EventTimeStart` |

```c
struct EventTimeStart {
    int32_t Start;        // start time; -1 is kept as 0xFFFFFFFF
};
```

```
S2C GTM0GD1000100@EventTime=/Start=100
```

The start notice, sent to every member when the event starts.

## D1/03 EventTime

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct EventTime` |

```c
struct EventTime {
    int32_t  Start;       // start time; -1 is kept as 0xFFFFFFFF
    int32_t  End;         // end time
    uint32_t Now;         // server time; the countdown is End - Now, 0xFFFFFFFF once Now is past End
};
```

```
S2C GTM0GD1000300@EventTime=/Start=100/End=500/Now=200
```

The schedule refresh. The client stores all three values; a later notice
replaces them.

## D1/04 EventTimeReq

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | room service | 0 | [D1/05 EventTimeReqCheck](#d105-eventtimereqcheck) | `struct EventTimeReq` |

```c
struct EventTimeReq {
    uint64_t NN;          // account identity, 16 hex
};
```

```
C2S GTM0GD1000400@EventTimeReq=/NN=0123456789ABCDEF
```

The client sends it while entering an event room, before the room `DE`, and
does not wait for the answer. A server answers it before it answers `DE`.

## D1/05 EventTimeReqCheck

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct EventTimeReqCheck` |

```c
struct EventTimeReqCheck {
    int32_t  Start;       // start time; -1 is kept as 0xFFFFFFFF
    int32_t  End;         // end time
    uint32_t Now;         // server time; the countdown is End - Now, 0xFFFFFFFF once Now is past End
};
```

```
S2C GTM0GD1000500@EventTimeReqCheck=/Start=100/End=500/Now=200
```

The client stores `Start`, `End` and the countdown `End - Now`.

## D1/08 EventTime close

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct EventTimeClose` |

```c
struct EventTimeClose {
    uint32_t Close;       // close time
    uint32_t ECM;         // purpose unknown (unverified); when absent the client reads 0xFFFFFFFF
};
```

```
S2C GTM0GD1000800@EventTime=/Close=510/ECM=2
```

The close notice, sent to every member when the room closes.

## Sequence

```
C2S GTM0GD1000400@EventTimeReq=/NN=0123456789ABCDEF
S2C GTM0GD1000500@EventTimeReqCheck=/Start=100/End=500/Now=50
S2C GTM0GD1000100@EventTime=/Start=100
S2C GTM0GD1000300@EventTime=/Start=100/End=500/Now=200
S2C GTM0GD1000200@EventTime=/End=500
S2C GTM0GD1000800@EventTime=/Close=510/ECM=2
```

The query and its answer happen once per entry; the four notices go to
every member as the event starts, is refreshed, ends and closes.
