# A0 Trade entry

A0 opens a trade. Subtype 00 carries two messages: `TrID`, which the
inviter sends to the invitee through the relay, and `TrEnt`, which the
inviter sends to the trade service
([services.md](../services.md#trade-service)). The sequence, the peer
controls and how the client finds the trade service are in
[trade.md](../../flows/trade.md).

## A0/00 TrID and TrEnt

### TrID

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| P2P | relayed | 0 | none | `struct TrID` |

```c
struct TrID {
    uint64_t ID;          // the 16-hex address the trade service answers from
};
```

```
P2P GTM0GA0000000@TrID=/ID=0000000000000001
```

The accepted inviter (side 0) tells the invitee which address the trade
service answers from, then sends `TrEnt`. A server relays TrID only
between a pair that has agreed to trade and does not answer it.

### TrEnt

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | trade service | 0 | [A1/00 TrEntAns](A1.md#a100-trentans) | `struct TrEnt` |

```c
struct TrEnt {
    uint64_t NN[2];       // self|peer game identities, 16 hex each
    uint32_t HID[2];      // self|peer POL handle index, at most 0x7FFFFFFF
    uint32_t Dm[2];       // self|peer, 0..255, purpose unknown (unverified)
    uint32_t Vol[2];      // self|peer, 0..65535, purpose unknown (unverified)
};
```

```
C2S GTM0GA0000000@TrEnt=/NN=0000000000000001|0000000000000002/HID=0|0/Dm=0|0/Vol=0|0
```

Only side 0 sends TrEnt. Each field holds `self|peer`; `NN` are 16-hex
identities, the others decimal. The first `NN` must be the authenticated
sender and the second the invitee that accepted. A server answers both
players with TrEntAns and then [A2/18 Init](A2.md#a218-init).
