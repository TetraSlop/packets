# A1 Trade entry answer

A1 acknowledges an [A0/00 TrEnt](A0.md#a000-trid-and-trent). The trade
service ([services.md](../services.md#trade-service)) sends it to both
players. It must never come from a player: the client does not
authenticate the sender and adopts whoever sent TrEntAns as the trade
service. The sequence is in [trade.md](../../flows/trade.md).

## A1/00 TrEntAns

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | trade service | 0 | none | `struct TrEntAns` |

```c
struct TrEntAns {
    int32_t Ans;          // 1, entry accepted
};
```

```
S2C GTM0GA1000000@TrEntAns=/Ans=1
```

Both clients poll for A1, so a server sends it to both sides, followed by
[A2/18 Init](A2.md#a218-init).
