# 80 Init

Player initialization and guild registration, sent to the
[shop service](../services.md#shop-service), whose identity the client
learned from [E2/00 TeachDVAns](E2.md#e200-teachdvans). The reply is
[81/00 InitAns](81.md#8100-initans); the guild picker and the second Init
are described in [startup.md](../../flows/startup.md).

## 80/00 Init

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | shop service | 0 | [81/00 InitAns](81.md#8100-initans) | `struct Init` |

```c
struct Init {
    uint64_t NN;            // game identity, 16 hex digits
    uint32_t HID;           // POL handle slot; always 0
    uint8_t Dm;             // profile directory, the `D` of TeachDVAns
    uint16_t Vol;           // profile volume, the `V` of TeachDVAns
    uint8_t CN[16];         // character name as hex byte pairs, at most 16 bytes
    uint64_t GID;           // character identity, 16 hex digits; 1 in the captured startup
    int32_t L;              // locale, signed; 0 in the captured startup
    uint8_t GLD;            // guild selection, 0 none, 1..3
};
```

```
C2S GTM0G80000000@Init=/NN=0000000000000001/HID=0/Dm=1/Vol=1/CN=416C696365/GID=0000000000000001/L=0/GLD=0
```

The client may send any subtype; the reply repeats it. The client sends the
first Init before its save file read has finished, so the first Init always
carries `GLD=0` even for a registered account. A second Init with a nonzero
`GLD` follows the guild picker.
