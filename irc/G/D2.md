# D2 Match offer

D2 offers an event table to the selected players, then starts or cancels
the accepted offer. The [room service](../services.md#room-service) sends
both messages. The client answers an offer with
[D3/00 MuchMakeAns](D3.md#d300-muchmakeans). The proposal rules are in
[event-matches.md](../../flows/event-matches.md#sequence).

## D2/00 MuchMake

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | [D3/00 MuchMakeAns](D3.md#d300-muchmakeans) | `struct MuchMake` |

```c
struct MuchMake {
    uint32_t TblNo;       // table number of the offered table
    uint64_t TblId;       // table identity, 16 hex
};
```

```
S2C GTM0GD2000000@MuchMake=/TblNo=1/TblId=0123456789ABCDEF
```

Sent to each proposed participant.

## D2/01 MuchMake start

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct MuchMakeStart` |

```c
struct MuchMakeStart {
    int32_t Start;        // 1 starts the accepted offer; -1 cancels an offer that was already accepted
};
```

```
S2C GTM0GD2000100@MuchMake=/Start=1
```

Sent to each participant. A `Start=1` that arrives before the client has
sent its answer is discarded when the answer goes out, so a server sends
`Start=1` only after every participant answered `Ans=1`. After `Start=1`
the client claims the table with [41/01 GameEN](41.md#4101-gameen).

## Sequence

```
S2C GTM0GD2000000@MuchMake=/TblNo=1/TblId=0123456789ABCDEF
C2S GTM0GD3000000@MuchMakeAns=/Ans=1/TblNo=1/TblId=0123456789ABCDEF
S2C GTM0GD2000100@MuchMake=/Start=1
C2S GTM0G41000100@GameEN=/NN=0123456789ABCDEF/HID=0/Dm=1/Vol=1/CN=416C696365/HN=416C696365/L=1
```

The offer and the answer repeat for each participant; `Start=1` follows the
last acceptance and each client then enters the table admission of
[41.md](41.md).
