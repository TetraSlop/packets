# 22 Trade invitation answer

The invitee's answer to a [21/00 Tr](21.md#2100-tr) invitation, sent back
to the inviter through the server's relay. Its place in the trade is in
[trade.md](../../flows/trade.md).

## 22/00 TrAns

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| P2P | relayed | 0 | none | `struct TrAns` |

```c
struct TrAns {
    int32_t  Ans;         // 1 accepts; -1 refuses, sent alone
    uint64_t NN;          // invitee's game identity, 16 hex; only with Ans=1
    uint32_t HID;         // invitee's POL handle index; only with Ans=1
    uint32_t Dm;          // invitee's profile directory number; only with Ans=1
    uint32_t Vol;         // invitee's profile volume number; only with Ans=1
};
```

```
P2P GTM0G22000000@TrAns=/Ans=1/NN=0000000000000002/HID=0/Dm=0/Vol=0
P2P GTM0G22000000@TrAns=/Ans=-1
```

The body is one section. The examples are built from the field list; no
capture of them is recorded (unverified). A server relays the answer only
between a pair allowed by the
[peer relay guard](../envelope.md#relay-guard) and records a positive
answer: the accepted inviter becomes side 0 and the invitee side 1, and the
pair may then register with [A0/00 TrEnt](A0.md#a000-trid-and-trent).
