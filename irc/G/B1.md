# B1 Shop entry

B1 acknowledges a [B0/00 ShReq](B0.md#b000-shreq). The shop service
([services.md](../services.md#shop-service)) sends it before the shop
session opens; it is not sent for the auction collection entry B0/01. The
sequence is in [shop.md](../../flows/shop.md).

## B1/00 ShEnter

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | shop service | 0 | none | `struct ShEnter` |

```c
struct ShEnter {
    uint32_t EN;          // 1, entry accepted
};
```

```
S2C GTM0GB1000000@ShEnter=/EN=1
```

The client then waits for [B2/13 Init](B2.md#b213-init) in its shop form,
which carries the session number.
