# 24 Save

The table and game editors can save their current values as personal
defaults. The client sends 24 to the
[room service](../services.md#room-service) when either save flag is 1,
otherwise [14 Apply](14.md) with the current table settings. Both `Tet` and
`Tab` are always present; the flags say which groups to persist. Where the
values land in the save file is in
[save-file.md](../../file/save-file.md); the editors are in
[startup.md](../../flows/startup.md#later-saves) and
[tables.md](../../flows/tables.md#sequence).

## 24/00 Save

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | room service | 0 | none | `struct Save` |

```c
struct Save {
    struct {
        uint32_t Tbl;       // 1 persists Tab
        uint32_t Game;      // 1 persists Tet
    } Save;
    struct {
        uint32_t bm;        // wager, 0..2000
        uint8_t du;         // double-up flag
        uint8_t st;         // special tiles flag
        uint8_t cb;         // cb tiles flag
        uint8_t ca;         // spinners flag
        uint8_t gs;         // departure rule, 0..2
        uint8_t tl;         // time limit, 0..5
    } Tet;                  // saved game defaults
    struct {
        uint8_t in;         // observe setting, 0..2
        uint32_t lu;        // card upper bound
        uint32_t ll;        // card lower bound
        uint32_t au;        // rank upper bound
        uint32_t al;        // rank lower bound
        uint8_t co;         // comment index, 0..8
        uint8_t pa;         // password enabled
        uint8_t pw[12];     // password as hex byte pairs, up to 12 bytes on the wire; the save file keeps 10
    } Tab;                  // saved table defaults
};
```

```
C2S GTM0G24000000@Save=/Tbl=1/Game=1@Tet=/bm=1234/du=1/st=0/cb=1/ca=0/gs=2/tl=5@Tab=/in=2/lu=98765/ll=123/au=321/al=123/co=8/pa=1/pw=61626364
```

The client does not wait for an acknowledgement; none has been found.
Saving defaults does not change the current table's rules.

Server choice: a server persists only the flagged groups and rejects a
selected password longer than 9 bytes, because the client reads the saved
password into a 10-byte field that needs a terminator.
