# D0 Event entry

D0 is the admission answer the [room service](../services.md#room-service)
sends when a client enters an event room, after the room `DE` has been
answered. There is no client `D0` request. The entry sequence is in
[event-rooms.md](../../flows/event-rooms.md#sequence).

## D0/00 EventEn

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct EventEn` |

```c
struct EventEn {
    int32_t Ans;          // admission result, see the table
};
```

```
S2C GTM0GD0000000@EventEn=/Ans=1
```

| `Ans` | Client behaviour |
| --- | --- |
| 1, 2, 2147483647 | the room is entered |
| 0 | the client keeps waiting for another `D0` |
| -32870 | denied: the client leaves the room by itself, then shows the rejection notice |
| other negative | generic failure |

The client reads a `D0` only after the room has answered its `DE` with
`DS`, so a server sends `DS` and the roster updates first and `D0` last.
On `Ans=-32870` the client sends an ordinary room `PC` before the notice;
the cleanup is in
[event-rooms.md](../../flows/event-rooms.md#exit).
