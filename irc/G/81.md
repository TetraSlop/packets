# 81 InitAns

The answer the [shop service](../services.md#shop-service) gives to
[80/00 Init](80.md#8000-init). What the client does after a success, and
which answer a server gives to each `GLD`, is in
[startup.md](../../flows/startup.md#guild-choice).

## 81/00 InitAns

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | shop service | 0 | none | `struct InitAns` |

```c
struct InitAns {
    uint32_t Ans;   // 1 existing player, continue; 2 reread the save file
};
```

```
S2C GTM0G81000000@InitAns=/Ans=1
```

The subtype repeats the request's. On `Ans=2` the client rereads
`U/g/TM0DataFile` strictly after its first read has completed.
