# 85 OptAns

The answer to [84/00 Opt](84.md#8400-opt), from whichever service received
the Opt, see [services.md](../services.md).

## 85/00 OptAns

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | service that received the Opt | 0 | none | `struct OptAns` |

```c
struct OptAns {
    uint32_t Ans;   // 1 saved
};
```

```
S2C GTM0G85000000@OptAns=/Ans=1
```
