# 2E CheckJoinTable_Ans

The answer the [room service](../services.md#room-service) gives to
[2D CheckJoinTable](2D.md). The client reads it only on its recovery path,
described in [tables.md](../../flows/tables.md#exit).

## 2E/00 CheckJoinTable_Ans

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service to the probing client | 0 | none, or [20/00 ExitCh](20.md#2000-exitch) from the recovery path | `struct CheckJoinTableAns` |

```c
struct CheckJoinTableAns {
    uint32_t Join;   // 1 when the client may join the table
    uint32_t Mem;    // 1 when the client is already a member of the table
};
```

```
S2C GTM0G2E000000@CheckJoinTable_Ans=/Join=1/Mem=0
```

The client combines the two fields as `Join | (Mem << 1)` and only tests
whether the result is zero:

| Join | Mem | Recovery action |
| --- | --- | --- |
| 0 | 0 | Skip table channel cleanup |
| any other | | Send [20 ExitCh](20.md#2000-exitch) to the table, then return to the room channel |

No consumer distinguishes the two bits.

Server choice: answer `Join=1/Mem=1` to a registered participant; for others
set `Mem` from seat availability and `Join` from seat availability or an
available spectator preview.
