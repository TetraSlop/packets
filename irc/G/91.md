# 91 Event cards reply

91 is the answer of the [event card service](../services.md#event-card-service)
to [90/00 CardReq](90.md#9000-cardreq). The visit it opens is in
[event-cards.md](../../flows/event-cards.md).

## 91/00 CardEnt

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | event card service | the sequence number of the request | none | `struct CardEnt` |

```c
struct CardEnt {
    int32_t Ans;          // positive opens the collection screen; -32870 denies entry
};
```

```
S2C GTM0G91000001@CardEnt=/Ans=1
```

On a positive `Ans` the client opens the collection screen and waits for
[B2/13 EcmInit](B2.md#b213-init) from the same service, with argument 0.
`-32870` is the denial value the client expects.
