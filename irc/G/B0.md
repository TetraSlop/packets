# B0 Shop request

B0 opens a session on the shop service
([services.md](../services.md#shop-service)). The client learns the shop
service's address at startup from
[E2/00 TeachDVAns](E2.md#e200-teachdvans). Subtype 00 enters the shop and
subtype 01 the auction collection; both are answered on [B2](B2.md). The
order of messages is in [shop.md](../../flows/shop.md) and in the
[auction collection sequence](../A.md#sequence).

Server choice: the shop service's address is POL service 0x300, sent as
`0x300 XOR 0xB62DC8D0E4BCBB90`.

## B0/00 ShReq

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | shop service | 0 | [B1/00 ShEnter](B1.md#b100-shenter) | `struct ShReq` |

```c
struct ShReq {
    uint64_t NN;          // player game identity, 16 hex; must match the authenticated account
    uint32_t HID;         // POL handle index
    uint32_t Dm;          // 0..255, purpose unknown (unverified)
    uint32_t Vol;         // 0..65535, purpose unknown (unverified)
    uint8_t  CN[16];      // character name, hex; must match the account
};
```

```
C2S GTM0GB0000000@ShReq=/NN=0000000000000001/HID=0/Dm=0/Vol=0/CN=4C6F63616C506C61796572
```

A server answers with ShEnter followed by [B2/13 Init](B2.md#b213-init)
in its shop form.

## B0/01 ShReq

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| C2S | shop service | 0 | [B2/13 Init](B2.md#b213-init) | `struct ShReq` |

```c
struct ShReq;             // the same fields as B0/00
```

```
C2S GTM0GB0000100@ShReq=/NN=0000000000000001/HID=0/Dm=0/Vol=0/CN=4C6F63616C506C61796572
```

The client sends it to collect settled auction proceeds. There is no B1
reply. A server answers with Init in its auction collection form, then
[B2/20 Data](B2.md#b220-data) and [B2/21 Card](B2.md#b221-card).
