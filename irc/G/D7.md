# D7 Announcements

D7 pushes scrolling announcement text to every member of an event room from
the [room service](../services.md#room-service). The room context is in
[event-rooms.md](../../flows/event-rooms.md#sequence).

## D7/00 ETelop

| Direction | Service | Argument | Reply | Body |
| --- | --- | --- | --- | --- |
| S2C | room service | 0 | none | `struct ETelop` |

```c
struct ETelop {
    uint32_t ID;          // announcement identifier; must exceed the last accepted one
    uint32_t Lp;          // loop count, positive
    uint32_t Pg[2];       // page index|page total, at most 10 pages
    uint8_t  St[199];     // page text, hex, at most 199 bytes per page
};
```

```
S2C GTM0GD7000000@ETelop=/ID=1234567/Lp=2/Pg=0|1/St=4F6C64
S2C GTM0GD7000000@ETelop=/ID=1234567/Lp=2/Pg=1|1/St=4F6C64
```

Text arrives in pages of hex-encoded bytes. The client shows nothing until
the last page of a complete ascending group has arrived, then shows the
whole announcement. Out-of-order or duplicated pages are dropped and an
`ID` not above the last accepted one is ignored. Each message stays within
the 447-byte body limit.
